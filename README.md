# Vive con IA CRM

CRM personal para gestión de prospectos de [Vive con IA](https://vivecon.ia).

## Stack

- React + Vite + TypeScript
- Tailwind CSS + Shadcn UI
- Supabase (DB + Realtime)
- Zustand (estado)
- Vercel (deploy)

## Setup local

1. Clonar repo
2. `npm install`
3. Copiar `.env.example` a `.env.local` y rellenar claves de Supabase
4. `npm run dev`

## Deploy

Conectar repo en Vercel. Añadir variables de entorno en el dashboard de Vercel.
